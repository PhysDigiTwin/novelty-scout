# Novelty Assessment: Extra-CoT (a155cec9)

## Paper Summary
Extra-CoT proposes a three-stage framework for extreme-ratio Chain-of-Thought compression with a semantically-preserved compressor, mixed-ratio SFT, and CHRPO (Constrained Hierarchical Ratio Policy Optimization) for RL.

## Prior Work Audit

### Direct Predecessors
- **TokenSkip** (Xia et al., 2025): Pruning-based SFT with mixture of ratios, using importance estimator (LLMLingua-2). The three-stage pipeline (compressor → SFT → RL) is architecturally identical.
- **CTS** (Yuan et al., 2025): Perplexity-based token importance for CoT compression, also SFT-based.
- **LLMLingua-2** (Pan et al., 2024): Bi-encoder token classification for extractive compression. Extra-CoT's compressor inherits this exact architecture (Longformer + bi-encoder classification head).
- **C3oT** (Kang et al., AAAI 2025): Uses GPT-4 for compression supervision, condition-prompt SFT. Mentioned in related work but not compared experimentally.
- **Thinkless/DeGRPO** (Fang et al., 2025): RL-based mode selection for reasoning length. Extra-CoT's CHRPO follows the same RL-for-compression paradigm.

### Genuinely Novel Components
1. **Formula-aware annotation**: Using GPT-4o with indexed CoT to generate keep/drop labels at the formula level. This is a specialized domain adaptation of LLMLingua-2's general-purpose compression.
2. **Extreme-ratio focus**: Existing methods (TokenSkip, CTS) target moderate compression (50-60%). Extra-CoT's focus on γ ≤ 0.4 where baselines collapse is a genuine empirical contribution.
3. **Hierarchical reward in CHRPO**: Separating ratio selection reward (control-head) from execution reward (main) is a reasonable RL engineering improvement.

### Incremental/Overclaimed
1. **Pipeline architecture**: The three-stage (compressor → SFT → RL) follows TokenSkip exactly. The "novel" claim in the abstract overstates the architectural novelty.
2. **Question-aware attention**: Global attention on question tokens in the Longformer is a standard technique, not a methodological contribution.
3. **CHRPO vs. DeGRPO**: Both use RL to optimize compression policy; the hierarchical decomposition is incremental.
4. **Missing C3oT comparison**: C3oT uses GPT-4 for compression — directly comparable to Extra-CoT's GPT-4o-based annotation. The omission weakens the claim of superiority.

## Verdict Implications
The paper's core contribution (domain-specialized compressor for math) is a solid engineering advance but represents a narrower novelty claim than the framing suggests. The pipeline architecture and RL optimization follow established patterns. Missing comparison with C3oT is a significant gap for ICML-level work.
