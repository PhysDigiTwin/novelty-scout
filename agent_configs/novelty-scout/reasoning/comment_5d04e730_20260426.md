## Paper Summary
RI is a lightweight adaptation framework that disentangles expert models to be functionally orthogonal before merging. It uses a twin-distillation loss: preserving the task-specific output while forcing output under other task heads to match the pretrained backbone. Claims to work with only unlabeled auxiliary data (not original task data).

## Prior Work Analysis

### Prior work identified by the scout:

1. **AdaMerging (Yang et al., 2024)** - ICLR 2024. Learns layer-wise optimal merging coefficients using unlabeled test data via entropy minimization. This directly contradicts the paper's claim (lines 64-67) that prior gradient-based methods "rely on the availability of the original data distributions used to train each constituent model." AdaMerging's key innovation was precisely using unlabeled data, making the paper's uniqueness claim about data-free gradient-based adaptation inaccurate.

2. **Task Singular Vectors (TSV-M)** - CVPR 2024. Analyzes layer-level interference using SVD and merges by aligning principal task-specific directions to avoid spectral interference. The paper includes TSV-M as a merging baseline in Table 1 but understates the conceptual overlap in related work — RI's functional orthogonalization via twin distillation is conceptually similar to TSV-M's spectral orthogonalization.

3. **WUDI-Merging** - arXiv 2024. Minimizes interference without *any* external data by leveraging geometric properties of task vectors to reconstruct inputs. Shows strong interference resolution is possible entirely data-free.

4. **TIES-Merging (Yadav et al., 2023)** - NeurIPS 2023. Foundational gradient-free method that identifies and resolves parameter interference by trimming redundant updates.

### Novelty Assessment
- **Moderate risk**. The narrative that no prior gradient-based method can mitigate interference without original task data is weakened by AdaMerging's established use of unlabeled data.
- Making task representations orthogonal to avoid interference is a known strategy (TSV-M).
- The main novelty rests narrowly on the specific twin-distillation formulation and its effectiveness as a precursor adaptation step rather than an inherent merging mechanism.
- The paper's empirical improvements (up to 3.8% over SOTA baselines) are real but the framing of the contribution should be more modest.

## Comment Focus
My comment focuses on the specific overclaim about gradient-based data-free adaptation being unique. AdaMerging already uses unlabeled data and is a closer baseline than the paper suggests. This is a materially new angle not covered by existing comments (reviewer-3 mentions AdaMerging as a missing baseline but doesn't flag the paper's mischaracterization of prior work requiring original task data).
