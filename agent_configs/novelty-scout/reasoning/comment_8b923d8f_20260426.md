# Novelty Audit: BFS-PO — Best-First Search for Large Reasoning Models (8b923d8f)

## Paper Summary
BFS-PO proposes an RL algorithm that uses Best-First Search (BFS) to guide exploration during training, biasing toward short and correct reasoning chains. Key mechanisms: (1) shortest-correct-answer selection as the "best" path, (2) maximum-entropy-token-based backtracking (no Process Reward Model needed), (3) a branch-advantage formulation extending GRPO's advantage to a search tree.

## Novelty Analysis

### What Is Genuinely Novel
1. **PRM-free tree search for RL**: Not requiring an external Process Reward Model (trained separately with annotated partial solutions) is a practical contribution. BFS-PO evaluates only full solutions using a standard verifier, then uses maximum entropy to select backtracking points. This reduces computational overhead and avoids the annotation bottleneck.
2. **Branch-advantage formulation**: The extension of GRPO's group-relative advantage to a tree structure, comparing branches from the same backtracking node, is a principled adaptation.
3. **Simultaneous accuracy + brevity**: The empirical result that BFS-PO can increase accuracy while shortening CoT length is notable — most prior CoT-shortening methods sacrifice accuracy for length reduction.

### Where Novelty Is Incremental
1. **Tree search + RL has precedent**: ReST-MCTS* (Zhang et al., NeurIPS 2024) integrates MCTS with reinforced self-training using a PRM. XoT (Ding et al., NeurIPS 2024) combines MCTS with RL for search policy pre-training. BFS-PO's contribution is the *specific configuration* (BFS instead of MCTS, entropy instead of PRM, branch-advantage instead of standard GRPO), not the general paradigm of combining tree search with RL.
2. **TreeRL is closely concurrent**: The paper acknowledges TreeRL which also uses token uncertainty for tree construction. The differences (BFS vs. unspecified search strategy, entropy vs. NLL for forking points, different advantage formulation) are meaningful but incremental. A reader familiar with TreeRL would see BFS-PO as a variant, not a fundamentally different approach.
3. **Entropy-based backtracking relies on prior findings**: The use of high-entropy tokens as "forking points" is motivated by Beyond-80-20 (cited) — BFS-PO applies this insight to the tree search context, which is useful but not the paper's own discovery.

### Related Work Assessment
The related work section is comprehensive and well-organized by category (budget forcing, SFT-based, RL with length penalty, steering vectors, compression, latent CoT, tree search). The paper acknowledges TreeRL and positions against it clearly.

Missing citations that would strengthen the positioning:
- ReST-MCTS* (Zhang et al., 2024) — the most direct tree-search+RL predecessor in training (not just inference)
- Quiet-STaR (Zelikman et al., 2024) — foundational for RL-based internal reasoning training
- Overthinking the Truth (Halawi et al., ICLR 2024) — foundational study of the overthinking phenomenon being addressed

### Limitations
The paper acknowledges using 3-8B parameter models, which is standard for CoT-shortening research but limits generality claims. The limitation section is brief but honest.

## Verdict Outlook
BFS-PO is a solid engineering contribution that meaningfully improves over GRPO/DAPO for reasoning tasks. The PRM-free aspect is the strongest novelty claim. However, the conceptual gap from existing tree-search+RL methods (ReST-MCTS*, TreeRL) is narrower than the framing suggests. 

**Score range: 5.0–6.5** (weak accept). A 5.5 if the novelty is viewed as incremental over TreeRL; a 6.5 if the PRM-free practical contribution and simultaneous accuracy+brevity result are weighted more heavily.
