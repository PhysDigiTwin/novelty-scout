# Novelty Analysis: VIA-Bench — Visual Illusions Benchmark

**Paper ID:** 0cd2f239-4b8a-4765-a7ea-145cbe9a3e01
**Title:** Seeing Is Believing? A Benchmark for MLLMs on Visual Illusions and Anomalies
**Date:** 2026-04-28

## Paper Claims

1. First benchmark targeting MLLM robustness on visual illusions and anomalies
2. 1K+ high-quality QA pairs requiring nuanced visual reasoning
3. CoT reasoning provides "negligible robustness" — "brittle mirages"
4. Fundamental divergence between machine and human perception

## Prior-Art Analysis

### Direct Prior Art: HallusionBench

HallusionBench (Guan et al., 2024) is an established diagnostic suite for visual hallucination and reasoning failure in MLLMs. It already covers much of the perceptual grounding failure space that VIA-Bench claims to pioneer. HallusionBench specifically tests whether models rely on visual input vs. language priors — the exact same construct VIA-Bench centers its novelty on.

While VIA-Bench's focus on classical perceptual illusions (Thatcher effect, spinning wagons) differs from HallusionBench's hallucination-oriented images, the conceptual motivation and evaluation setup overlap substantially. The paper does present a different image domain, but the evaluation paradigm (testing visual vs. linguistic reasoning) is preempted.

### Broader Benchmark Prior Art

Multiple pre-existing benchmarks evaluate MLLM perceptual robustness:
- VQA-v2 (Goyal et al., 2017) — visual question answering
- MM-Vet (Yu et al., 2023) — multimodal capability assessment
- MMBench (Liu et al., 2023) — multimodal reasoning

## Critical Novelty-Killing Evidence

### Linguistic Contamination

The paper's own blind evaluation (Table 1) shows GPT-4-Turbo with vision disabled achieves 87.95% accuracy on the Motion Illusions (MI) category — above chance (25% for 4-option MCQ). This directly refutes the paper's core claim in Section 2.2 that "correct options y are statistically independent of textual priors in q" to "isolate visual intelligence."

If a text-only model can achieve near-ceiling performance on a category, then:
1. The questions in that category are answerable from linguistic priors alone
2. The benchmark does not require visual perception for that category
3. The claim of "isolating visual intelligence" is falsified

The 87.95% figure is not marginal contamination — it is a terminal validity failure for the MI category and raises serious concerns about other categories where blind performance is elevated.

### Statistically Insignificant CoT "Paradox"

The paper's headline finding — that CoT reasoning provides "negligible robustness" (Section 4.4) — reports a mean accuracy delta of 0.15% for Gemini-2.5-pro. On a 1,004-sample dataset, this corresponds to approximately 1.5 questions — well within random variation. Without reporting standard deviations or formal significance testing, the CoT paradox claim lacks statistical support.

### Missing Negative Controls

The benchmark lacks "negative control" images (standard, non-illusory images paired with the same question templates). Without these, it is impossible to distinguish between:
1. Models performing worse on illusion images because they require genuine visual reasoning
2. Models performing worse on illusion images because the images are inherently more challenging/confusing

A benchmark that claims to measure "visual intelligence" against "common-sense priors" needs to demonstrate that the performance deficit is specific to the illusion condition, not a general difficulty effect.

### Code Not Linked

The three GitHub URLs associated with the paper are all reference model repositories (Qwen2.5-VL, InternVL, Qwen3-VL), not VIA-Bench construction code, evaluation harnesses, or dataset files. This prevents independent verification of the benchmark construction methodology.

## Novelty Assessment Summary

**Novelty Rating: Low.** The benchmark's core innovation — testing whether MLLMs rely on visual input vs. language priors — is preempted by HallusionBench. The specific image domain (classical perceptual illusions) differs, but the evaluation paradigm is not novel. More critically, the paper's own blind evaluation refutes the core claim of isolating visual intelligence, and the headline CoT finding lacks statistical support. These are not incremental novelty limitations — they are fundamental validity failures that make the benchmark unsuitable for its stated purpose.

The paper would need to: (1) clearly differentiate from HallusionBench on conceptual novelty, not just image domain; (2) decontaminate or remove categories where text-only models achieve high accuracy; (3) add negative controls; and (4) provide statistical support for claims.
