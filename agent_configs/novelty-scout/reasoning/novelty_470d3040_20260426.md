# Novelty Audit: MUNKEY — Machine UNlearning via KEY Deletion
## Paper: 470d3040-06cf-40f5-a216-ae4ee9250eee
## Date: 2026-04-26 10:34 UTC

### Reading Summary

I read the full paper PDF (23MB, 14 pages + appendix). MUNKEY proposes "unlearning by design" — training Vision Transformers with an external exemplar memory bank where each training instance gets a learnable token (key-value pair). At unlearning time, forget-set entries are removed from the memory. At inference, K-nearest neighbor retrieval from the remaining memory is used. Training uses stochastic pathway dropout to balance image-path and memory-path information flow.

### Own Prior-Work Analysis

I manually searched the paper's references and identified the closest architectural prior work:

1. **Memorizing Transformers (Wu et al., ICLR 2022)** — Uses the **exact same mechanism**: decoupled external key-value memory accessed via kNN retrieval at inference, trained jointly with transformer parameters. The paper acknowledges this in Section 2 but claims novelty in repurposing it for unlearning. However, the architectural core (key-value memory + kNN retrieval + transformer backbone) is fully anticipated. MUNKEY adds: (a) learnable exemplar tokens as values, (b) stochastic pathway dropout, (c) the deletion operation as "unlearning." The deletion is a trivial byproduct of the existing external memory design — removing entries from a key-value store is not a capability that requires invention.

2. **Retrieval-Augmented Classification / RAC (Long et al., 2022)** — Cited in Appendix A. Combines parametric classifier with non-parametric external memory retrieval. Same architectural family.

3. **Neural Turing Machines (Graves et al., 2014)** and **Memory Networks (Weston et al., 2015)** — Earlier decoupled memory architectures, also acknowledged.

### Novelty Assessment

**What is genuinely novel:**
- The application of external memory architectures to instance-level machine unlearning
- The specific training recipe: stochastic pathway dropout, retrieval-based regularization, Pathway Sensitivity Score (Ps)
- The empirical demonstration that this approach achieves competitive unlearning across vision benchmarks

**What bounds the novelty:**
- The core architecture (decoupled external memory + kNN retrieval + transformer) is pre-existing and acknowledged
- The deletion operation ("unlearning") is a trivial byproduct of having an external key-value store — no algorithmic contribution
- SISA already established "design-time" unlearning (though via different mechanism)
- The paper's claim to "paradigm shift" inflates the contribution

**Conclusion:** The paper makes a useful engineering contribution (applying external memory to unlearning with a specific training recipe) but the architectural innovation is incremental. The "unlearning by design" paradigm claim is overstated given SISA's prior work, and the core mechanism is a direct repurposing of pre-existing external memory architectures.
