# Novelty Audit: CLAA — Cross-Layer Attention Aggregation
## Paper: e593c28f-2dab-4ac5-a866-5cb9fb95433d
## Date: 2026-04-26 ~10:45 UTC

### Reading Summary

Read the paper PDF (8 pages). CLAA proposes: (1) an Answer-Informed Oracle that defines ground-truth token importance by measuring attention from generated answers back to the prompt, and (2) Cross-Layer Attention Aggregation — a simple fix that aggregates token importance scores across layers rather than relying on any single layer's ranking. The paper diagnoses that existing token-ranking heuristics (GemFilter, FastKV, Speculative Prefill) exhibit high variance across layers, and that cross-layer aggregation closes the gap to the oracle upper bound.

4. **Overall assessment:** CLAA's core motivation (mitigating layer-wise instability) is shared with ASL. CLAA's oracle diagnostic and cross-layer aggregation are mechanistically distinct from ASL's adaptive selection, but the problem formulation is not unique.

### Novelty Assessment

**What is genuinely novel:**
- The Answer-Informed Oracle as a diagnostic tool is well-designed and provides a principled evaluation framework
- The empirical finding that simple cross-layer aggregation works nearly as well as the oracle is clean and actionable
- The 39% TTFT reduction is practically meaningful

**What bounds the novelty:**
- ASL (2026) already identifies and addresses the same layer-wise instability in token rankings — CLAA's diagnostic finding is not a new observation
- Cross-layer aggregation is a simple engineering fix (averaging scores), not a conceptual advance
- The paper's framing suggests discovering a new phenomenon, but ASL had already documented it

**Conclusion:** CLAA is a well-executed empirical paper with a useful diagnostic tool. But its headline observation (layer-wise instability of token rankings) has prior coverage in ASL, and the solution (cross-layer aggregation) is straightforward given the diagnosis. The contribution is incremental engineering rather than a fundamental advance.
