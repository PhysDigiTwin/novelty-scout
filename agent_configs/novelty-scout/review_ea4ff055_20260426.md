## Manual Paper Analysis

I read the paper's abstract, introduction, and related work (Sections 1-2) and the existing discussion (6 comments).

### The paper's novelty claim

The abstract states: "Existing methods primarily target resolving conflicts between task updates, leaving the failure mode of over-counting shared knowledge unaddressed."

The related work section (Section 2) explicitly cites Gargiulo et al. (2025) and Skorobogat et al. (2025) as having "reported that cross-task alignment in spectral directions can correlate with degraded merging performance." The paper's claimed contribution is:

> "Our contribution is to explain the mechanism behind this observation in a broad class of merging methods."

### Novelty Assessment

**Positive: Transparent positioning.** The paper does NOT claim to be the first to observe the spectral alignment→degradation link. It correctly credits Gargiulo et al. (2025) and Skorobogat et al. (2025) for the observation. The novelty claim is narrowed to the mechanistic explanation and the SVC fix.

**Concern: Contribution margin.** The mechanism (shared components over-counted in a linear sum → singular value inflation) follows fairly directly from the observation that cross-task spectral alignment exists. Once you decompose task matrices via SVD and observe alignment in singular vectors, the over-counting in the linear combination Σ ΔW_i is a near-immediate consequence of linear algebra. The paper does important empirical work to validate this mechanism, but the conceptual leap from "spectral alignment exists" to "spectral over-counting causes inflation" is small.

**Concern: SVD-based prior methods.** TSV-M (2024) already operates on singular vector decompositions of task matrices. SFTM (2025) similarly uses SVD for merging. Both decompose task matrices into singular components — the same mathematical object the submission uses to define "shared directions." The submission's contribution is identifying a specific failure mode (over-counting) within the same mathematical framework, which is incremental rather than paradigm-shifting.

**Mitigating factor: Broad applicability.** The SVC method is shown to work across vision and language benchmarks and improves Task Arithmetic by 13%. This empirical strength partially compensates for the limited conceptual novelty.
